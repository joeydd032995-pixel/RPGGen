# Asset Sourcing

Only author-published assets with a verifiable redistribution license belong in the renderer path.
No game-cache extraction, fan-wiki models, or assets derived from RuneScape clients are permitted.

## Selected stack

### Environment: Kenney Nature Kit

- License: CC0 1.0
- Source: https://kenney.nl/assets/nature-kit
- Status: five selected GLBs imported with local checksums and provenance under
  `assets/models/kenney-nature/`.
- Use: trees, rocks, bushes, grass, and logs.

### Characters and equipment: KayKit

- Adventurers: https://kaylousberg.itch.io/kaykit-adventurers
- Fantasy Weapons Bits: https://kaylousberg.itch.io/fantasy-weapons-bits
- Character Animations: https://kaylousberg.itch.io/kaykit-character-animations
- License: CC0 1.0 on each author-published page.
- Status: imported from the free archives with archive and selected-file checksums under
  `assets/external/kaykit/`. The shipped reference actor is the Knight reduced with
  GLTF Transform and Meshoptimizer from 5,328 vertices/5,800 faces to 323 vertices/571 faces. The
  selected `sword_A` is reduced to 281 vertices/204 faces. Their composed runtime model remains
  inside the 2,048-vertex/face budget at 604 vertices and 775 faces.

KayKit is preferred over the newer Quaternius base because its silhouette and shared gradient atlas
fit the target while remaining substantially more plausible for a CPU renderer. The animation
archive is checksummed and licensed, but no animation-only GLB is shipped until keyframe sampling is
added; the current reference actor uses deterministic joint-label posing.

### Alternative modular characters: Quaternius Ultimate Modular Men/Women

- Men: https://quaternius.com/packs/ultimatemodularcharacters.html
- Women: https://quaternius.com/packs/ultimatemodularwomen.html
- Equipment: https://quaternius.com/packs/ultimaterpg.html
- License: CC0 1.0 on the author-published pages.
- Status: fallback if KayKit equipment swapping is insufficient.

The newer Universal Base Characters average roughly 13,000 triangles and are intentionally rejected
for the primary runtime path.

## 2D overlays

The minimap frame, status bars, panel interiors, slot states, and cooldown masks are generated by
`src/software-renderer/overlay.mjs`. This keeps the interface legally and visually distinct. If
item artwork is later needed, the preferred CC0 sources are:

- Kenney Fantasy UI Borders: https://kenney.nl/assets/fantasy-ui-borders
- Kenney RPG Expansion: https://kenney.nl/assets/ui-pack-rpg-expansion
- 7Soul1 CC0 medieval/fantasy icons:
  https://opengameart.org/content/496-pixel-art-icons-for-medievalfantasy-rpg
- Monogram CC0 bitmap font: https://datagoblin.itch.io/monogram

Do not copy the circular orb layout, minimap frame, inventory stonework, icons, fonts, or panel
silhouettes from any RuneScape client or screenshot.

## Import requirements

Every imported pack must include creator, source page, archive URL, retrieval date, license URL,
original archive SHA-256, selected-file SHA-256, and any conversion/simplification steps.
